# 2 号地球 · 雨林之境

中文浏览器 3D 雨林探索原型。玩家无需安装客户端，打开链接即可游玩。采用 Poly Haven CC0 专业植被模型、扫描根木与苔石、实拍地表材质和真实雨林 HDR 环境光，无运行时第三方资源请求。

## 玩法

- 点击「进入 2 号地球」。WASD 移动，Shift 快步，按住鼠标拖动环顾；方向键也可移动与转向。
- 手机：左下角摇杆移动，在场景中拖动环顾。
- 靠近发光标记，按 E 或点击提示，记录五种生命、种下三株树苗。
- M 打开可实时定位与快速前往的地图，J 打开图鉴，P 保存无界面风景照片。
- 可切换晴雨天气、开启合成环境声。Esc 暂停/关闭窗口。
- 图鉴和种植进度自动存入当前浏览器 localStorage；「操作说明」中可确认清空。不是多人世界，不含账号、后端或跨设备同步。

场景由授权资产进行环境美术构图，并非同一真实地点的完整扫描；并非所有植物模型都是摄影测量扫描。树木与植被不再由代码生成树冠和叶片。闪蝶采用 QweenH 的 CC BY 4.0 模型，保留蓝色翅面、褐色反面、触角及足部，飞行与振翅由程序驱动；并非动物扫描，未确定到具体种。地形、水体与交互标记由程序生成，音效由 Web Audio 合成，不含录音素材。来源及许可见 `public/ASSET-CREDITS.txt`，游戏内操作说明也有入口。

林冠、中层与林下分布覆盖完整可探索矩形，并向边界外延伸，保留溪流、小径和互动点的空隙。低画质保留相同的林冠与中层位置，只减少林下密度与绘制距离；不是只在入口铺设植被。

新增动物采用授权真实扫描：金色箭毒蛙为活体摄影测量；唐纳雀、绿鬣蜥、淡水蟹和天牛为博物馆标本扫描。首帧完成后单独加载，不占原首屏进度。入口左侧枯枝上可见鬣蜥，右侧榕树根上停有唐纳雀；其他小型动物需靠近小径和溪岸观察。动作是整体位移/停顿，不是骨骼动画；鬣蜥的扫描枯枝不会随动物转动。原五种记录、三株种植任务和存档键保持不变。

## 开发

Node.js 20.19+ 或 22.12+（本项目使用 Node.js 24）。

```sh
npm ci
npm run dev       # 监听 0.0.0.0:5173
npm test          # 数据、互动距离和进度持久化测试
npm run build
npm start         # Node.js 静态生产服务，0.0.0.0:4173（可用 PORT 修改）
```

生产部署可将 `dist/` 上传至任意静态站点托管，不需要服务器数据库。请勿用开发服务器作为公开生产服务。所有模型、材质、光照和 Three.js 均随构建产物提供；不注册 service worker。可用 `STATIC_DIR` 指定候选产物目录，并用不同 `PORT` 验证而不影响线上。

## 技术与边界

- Three.js、Vite，原生 JavaScript / CSS；无外部运行时图片或字体依赖。随站点提供 Noto Sans SC / Noto Serif SC 的界面用字子集（SIL OFL 1.1，见 `public/FONT-LICENSE.txt`）。修改中文文案后运行 `python3 scripts/subset-fonts.py` 更新子集（仅开发时访问 Google Fonts），或改用完整字体。
- WebGL 和硬件加速为必要条件；初始化失败会显示中文帮助。
- 按空间区块实例化绘制模型，共享材质与几何；软件渲染自动降低分辨率与植被数量。像素比上限为 1.4，移动端仍需具备基本 3D 性能。
- 所有交互在客户端执行，无采集、无网络账号，无付费功能。
- 浏览器拒绝本地存储时仍可游玩，并在保存失败时提示；无痕模式关闭后进度可能丢失。
